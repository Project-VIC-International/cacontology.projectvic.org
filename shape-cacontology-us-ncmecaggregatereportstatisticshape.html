Label

Aggregate Report Statistic Shape

Description

Validates published aggregate transparency statistics: each statistic must carry exactly one primary numeric value, a unit, and a reporting period. - Optional published change relative to the prior period. - Optional qualifier from the published source (e.g., 'more than'). - Optional links to the category, program, or concept nodes the statistic describes.
