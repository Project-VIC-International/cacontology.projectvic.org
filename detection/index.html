CAC CSAM Detection & Classification Ontology

Namespace: https://cacontology.projectvic.org/detection#

Definition: An ontology for representing Child Sexual Abuse Material detection and classification systems with gUFO foundational ontology enhancements for improved semantic precision, temporal modeling, and validation capabilities, extending UCO and CASE. This ontology covers automated detection tools, hash matching, machine learning models, and classification scales used in CSAM identification.
